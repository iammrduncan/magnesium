## Standing constraints

- Locked-down hosts are the target. Container flags must pass a strict validator; sandboxed by default; secrets pass by name only.
- Any UI that can type into an agent is a root-level control surface. It needs one front door, tokens kept server-side, and a supervised permission mode by default.
- One implementation per operation: the CLI, REST and MCP share operations. A UI uses the API, not its own path.
- **Fork discipline (D11):** track the server side closely; own `apps/web`. Put new features in our packages where that is natural. Mark every edit to an upstream file. Do the rename as one scripted change. Let the weekly per-file conflict report decide when to own a file outright (doc 11).
